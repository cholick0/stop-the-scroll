An entry for the [make.fun](https://make.fun) bounty **One Line to Stop the Scroll**: one line of text, at most 200 characters, that makes a stranger stop scrolling and smile.

## The entry

> You just stopped scrolling for a stranger's one line, and somewhere an algorithm quietly lost a bet.

## How it works

`main.ts` (Node 22) writes the line to `/output/entry.txt`, with a self-check gate (1–200 characters, one line, not blank) and a byte-for-byte read-back verification.

Run it with:

```sh
node main.ts
```
